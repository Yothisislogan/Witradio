# Composer fact files

The Count's anecdotes may only use facts from tonight's plan and from these
files (show bible: "Every anecdote is checked against a per-composer fact
file (dates, premieres, places) before air").

One plain-text file per composer, named after the composer as the catalog
spells it, lowercased with dashes: `johann-sebastian-bach.txt`,
`frederic-chopin.txt`. One fact per line; lines starting with # are ignored.

    # johann-sebastian-bach.txt
    Born March 21, 1685, in Eisenach.
    Thomaskantor in Leipzig from 1723 until his death in 1750.
    The Goldberg Variations were published in 1741.

Every number and name the Count says must appear here or in the plan, so a
wrong date in a fact file is a wrong date on air: check each line against a
reliable source.
